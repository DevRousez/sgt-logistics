# Especificaciones de la App Móvil (Spec-Driven Development)

En este directorio residen las especificaciones funcionales y técnicas de la aplicación móvil **operador_appsgt**.

## Metodología
1. Antes de codificar cualquier nueva pantalla, widget complejo o servicio nativo, se documenta aquí.
2. Copiar `template.spec.md` asignando un número correlativo (ej: `001-firma-digital-remision.spec.md`).
3. Toda especificación debe detallar:
   - Pantalla y componentes UI
   - Endpoints de SGTSITA a consumir
   - Manejo de estados (Carga, Éxito, Offline, Error)
   - Permisos de hardware (Cámara, GPS, Archivos)
